Weekly workflow

Add newly read papers

  1. Put new PDFs anywhere under your desktop papers folder.
  2. Move non-paper material into its Ignore folder.
  3. Run the importer, review the changes, and commit.
.venv\Scripts\python scripts\import_papers.py "C:\Users\cheth\Desktop\papers"

The importer merges duplicate arXiv papers and preserves existing catalog entries.

Plan a Monday session

Add papers by arXiv ID and attach any useful webpage, slides, notes, code, or dataset link.

.venv\Scripts\python scripts\add_session.py --paper 2501.12948 --link "Discussion notes|https://example.com/notes"

The date defaults to the next Monday. Use --date YYYY-MM-DD to edit another week.
